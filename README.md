# Commissio Ducalis 1408

This repository contains a TEI/XML digital edition of the Venetian ducal commission issued in 1408 to the Sindici Inquisitori, preserved in two manuscript witnesses.

The project provides a semi-diplomatic transcription and structured TEI/XML encoding of the document, modelling its linguistic, documentary, and administrative features in a machine-readable format. The edition supports historical, palaeographical, diplomatic, and prosopographical research and is published as a web edition using GitHub Pages.

## Project Overview

The edition follows the Text Encoding Initiative (TEI) Guidelines and is based on a comparative study of the two surviving manuscript witnesses. The encoding preserves the documentary structure and textual features while enabling digital analysis, interoperability, and long-term preservation.
